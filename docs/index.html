What it does

Prompt. Evaluate. Observe.

Everything a FileMaker developer needs to run serious AI workflows — without ever leaving their solution.

⚙

Multi-Model Routing

Route any prompt to any model — GPT-4o, Claude, Mistral, Llama — via OpenRouter, LM Studio, or any OpenAI-compatible endpoint. Endpoints, models, and sources are fully dynamic at runtime.

⚖

LLM-as-Judge

Designate a judge model to score and reason about output quality automatically. Evaluation as a first-class workflow.

📋

Prompt Library

Author and version prompts in JSON, Markdown, or plain text — with database variable injection baked in.

📊

Execution Tracing

Every run logged in full: model, endpoint, temperature, prompt version, output. Complete observability.

🤖

agentic-fm

Integrates with the Agentic FileMaker Coding framework for multi-step AI workflows.
